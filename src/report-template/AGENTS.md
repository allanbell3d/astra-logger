# Required HTML report format

These HTML files and README describe the required portable incident/repair report format, separate from core capture and eligibility. HTML generation and delivery are required; a publication service or catalog application is optional. Keep downloaded reports self-contained and readable offline. Keep unknown facts unknown, original diagnosis immutable, revisions/conflict checks meaningful and repair claims tied to performed verification. The example is fictional.

The corresponding helper/shell live under ../agent/astra/. Rendering and answer delivery are distinct. Preserve offline fallback and never claim publication from a saved file alone. Changes to duplicated/pinned delivery assets require explicit synchronization and hash verification; do not replace those copies casually.
