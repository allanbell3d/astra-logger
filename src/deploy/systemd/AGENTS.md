# Linux service examples

Files ending .example are templates, not installed or enabled services. Replace /ABSOLUTE/HOME and the example astra-health profile consistently. astra-health-dispatch.service is the fixed unit name invoked by the capture launcher; preserve that installed interface even when adapting its sample.

Validate service syntax and exact environment/paths on the intended Linux instance before installation. Do not infer a service's current running state, capture cadence or schedule authority from these files. Existing personal service definitions are private snapshots. Do not enable, restart or install services during a repository review.
